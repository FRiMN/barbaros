# Инструкции по сборке Flatpak-пакета (для разработчиков)

Эти инструкции предназначены для разработчиков, желающих собрать Flatpak-пакет для приложения.

## Предварительные требования

*   Установленные `flatpak`, `flatpak-builder`, `uv` и зависимости проекта (`uv sync`).
*   Настроенный репозиторий Flathub (для установки зависимостей).
*   Доступ в сеть при сборке: PySide6 6.12 ставится в модуль из PyPI (см.
  ниже, BAR-28).

## Сборка через invoke (рекомендуется)

Проект использует **[invoke](https://docs.pyinvoke.org/ru/stable/)** (см. `tasks.py`) для автоматизации сборки. 
Задачи выполняются через `uv run invoke <задача>`:

1.  **Сборка приложения** — `uv run invoke build_python`
2.  **Сборка Flatpak-репозитория** — `uv run invoke build_flatpak`
3.  **Создание bundle (`.flatpak`)** — `uv run invoke bundle`

Либо выполните полную сборку одной командой (включает компиляцию переводов, сборку Python-пакета, Flatpak-репозитория и bundle):

```sh
uv run invoke build
```

Другие полезные задачи:
*   `uv run invoke update_translations` — обновление файлов переводов (`.ts`).
*   `uv run invoke compile_translations` — компиляция переводов (`.ts` → `.qm`).
*   `uv run invoke clean` — удаление артефактов сборки.

## Ручная сборка (для детального контроля)

### 1.  Сборка приложения

```sh
uv build
```

Эта команда выполняет сборку вашего приложения.

### 2.  Сборка Flatpak-пакета

```sh
flatpak-builder --force-clean --repo=repo --install-deps-from=flathub build flatpak/barbaros.yaml
```

*   `--force-clean`:  Удаляет все предыдущие сборки, гарантируя чистое состояние. Это важно при внесении изменений в манифест или исходный код.
*   `--repo=repo`: Указывает локальный репозиторий (директорию) (`repo`), где будет размещен собранный Flatpak.  Этот репозиторий будет использоваться для установки и тестирования пакета.
*   `--install-deps-from=flathub`: Указывает, что зависимости, перечисленные в манифесте (`flatpak/barbaros.yaml`), должны быть установлены из Flathub.
*   `build flatpak/barbaros.yaml`: Запускает процесс сборки, используя файл манифеста `flatpak/barbaros.yaml`.

#### PySide6 в Flatpak-сборке (BAR-28)

Базовое приложение `io.qt.PySide.BaseApp` 6.11 содержит PySide6 6.11.3, а ветки
6.12 на Flathub нет. PySide6 < 6.12 по-прежнему распаковывает pickle из
`QSettings` (CWE-502, BAR-28), поэтому модуль `barbaros` в манифесте ставит
поверх базового приложения точный пин из PyPI:

```
pyside6-essentials==6.12.0
shiboken6==6.12.0
```

Пин задан отдельной командой `pip3 install --no-deps` в `flatpak/barbaros.yaml`
(в модуле включён `--share=network`, так что сборка скачивает колёса с PyPI).
После установки `flatpak/bar28_guard.py` проверяет, что импортируемый PySide6
>= 6.12, что он собран против той же минорной версии Qt и что `QSettings`
действительно отказывается десериализовать pickle, а не выполняет его. Если
проверка не проходит, сборка падает.

Проверить версию в собранном пакете:

```sh
flatpak run --command=python3 io.github.frimn.barbaros -c 'import PySide6; print(PySide6.__version__)'
```

Ожидается `6.12.0` или новее. Когда на Flathub появится ветка
`io.qt.PySide.BaseApp` 6.12, пин из PyPI и `bar28_guard.py` можно убрать,
подняв `base-version` (см. issue #15).

#### Известные ограничения и цена пина

Пин ставится поверх содержимого базового приложения, а `pip` не удаляет файлы,
которых нет в новой версии, поэтому в `/app` остаются артефакты PySide6 6.11.3
из BaseApp: `pyside6-6.11.3.dist-info`, `pyside6_addons-6.11.3.dist-info`,
`shiboken6_generator-6.11.3.dist-info`, 33 устаревших `.abi3.so` модулей
addons и библиотеки ffmpeg из base app (всего 134 файла, которых нет в
`RECORD` от `pyside6-essentials` 6.12; Qt-библиотек 6.11 не остаётся). Эти
файлы принадлежат базовому приложению, поэтому вычищать их в
`cleanup-commands` вслепую нельзя. На работу это не влияет: `import PySide6`
даёт 6.12.0, все Qt-библиотеки в `/app` — 6.12.0 (`qVersion()` == 6.12.0), а
приложение импортирует только Essentials (QtCore/QtGui/QtWidgets/QtDBus);
offscreen-smoke-тест собранного bundle (`import barbaros.main`, `QApplication`,
`QtDBus`) проходит.

Цена решения (зафиксирована для релиза): bundle вырос с 221 МБ (211 МиБ)
до 267 МБ (255 МиБ) — примерно +46 МБ (+21%); установленный размер — с
881 МБ до 1,1 ГБ. После появления на Flathub ветки BaseApp 6.12 пин из PyPI
и `bar28_guard.py` убираются — остатки исчезают вместе с ним (см. issue #15).

Страховка для старых runtime: если приложение всё же запустится на
PySide6 < 6.12, оно не читает файл настроек с диска вообще — существующий
конфиг уносится в карантин (best-effort бэкап), а сессия использует
in-memory объект с QSettings-совместимым API. Предпочтения в этом случае
сбрасываются, зато pickle не исполняется. Для Flatpak-артефакта это не
действует (в нём 6.12.0), это страховка для других/старых сборок.

### 3.  Добавление локального репозитория

Это нужно только один раз.

```sh
flatpak --user remote-add --no-gpg-verify local-repo repo
```

*   `--user`: Добавляет репозиторий для текущего пользователя.
*   `remote-add`:  Добавляет новый удаленный репозиторий Flatpak.
*   `--no-gpg-verify`: Отключает проверку GPG для локального репозитория. **Предупреждение:** Используйте только для локальных репозиториев. Никогда не отключайте проверку GPG для общедоступных репозиториев.
*   `local-repo`:  Имя, которое вы даете локальному репозиторию. Вы можете выбрать любое имя.
*   `repo`:  Путь к локальному репозиторию, который вы указали в команде `flatpak-builder`.

### 4.  Локальная установка Flatpak-пакета

```sh
flatpak --user install --or-update local-repo io.github.frimn.barbaros
```

*   `--user`: Устанавливает пакет для текущего пользователя.
*   `install`:  Устанавливает приложение Flatpak.
*   `--or-update`: Обновляет приложение, если оно уже установлено. Это удобно при повторной сборке и установке пакета.
*   `local-repo`: Имя локального репозитория, который вы добавили на предыдущем шаге.
*   `io.github.frimn.barbaros`:  Идентификатор приложения Flatpak, указанный в файле манифеста (`flatpak/barbaros.yaml`).

### 5.  Создайте одиночный установочный файл (bundle)

```sh
flatpak build-bundle repo barbaros.flatpak io.github.frimn.barbaros
```

Этот файл `.flatpak` можно распространять и устанавливать напрямую:

```sh
flatpak install barbaros.flatpak
```
